# Русская клавиатура для HarmonyOS 6

Приложение клавиатуры с поддержкой русского языка и автоматическими предложениями слов для HarmonyOS 6.

## Возможности

- ✨ Полная поддержка русского языка (QWERTY раскладка)
- 🔤 Поддержка английского языка
- 🔢 Цифровая раскладка с символами
- 💡 Автоматические предложения слов при вводе
- 🎯 Интуитивный и удобный интерфейс
- ⚡ Быстрое переключение между языками
- 📱 Оптимизировано для HarmonyOS 6

## Технические детали

### Раскладки клавиатуры

Приложение поддерживает три типа раскладок:

1. **Русская QWERTY** - полная русская раскладка с поддержкой верхнего регистра
2. **Английская QWERTY** - стандартная английская раскладка
3. **Цифровая** - цифры и специальные символы

### Система предложений слов

Движок предложений (`SuggestionEngine`) использует:
- Встроенный словарь часто используемых русских слов
- Алгоритм поиска по префиксу
- Ранжирование по частоте использования
- Самообучение (запоминает введенные слова)

### Управление вводом

`KeyboardController` управляет:
- Вводом текста через InputMethodEngine API
- Переключением раскладок
- Обработкой специальных клавиш (Shift, Backspace, Enter)
- Генерацией предложений в реальном времени

- **DevEco Studio**: 6.0 или выше
- **Устройство**: HarmonyOS 6.0+

## Сборка и установка

### 1. Открыть проект

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd harmonyoskeyboard

# Откройте проект в DevEco Studio
```

### 2. Настроить SDK

1. Откройте DevEco Studio
2. File → Project Structure
3. Убедитесь, что выбран HarmonyOS SDK API 20

### 3. Собрать проект

1. В DevEco Studio выберите устройство (эмулятор или реальное устройство)
2. Нажмите Build → Build Hap(s)/APP(s)
3. Дождитесь завершения сборки

### 4. Установить на устройство

1. Подключите HarmonyOS устройство или запустите эмулятор
2. Нажмите Run → Run 'entry'
3. Приложение будет установлено на устройство

## Активация клавиатуры

После установки приложения:

1. Откройте **Настройки** → **Система** → **Язык и ввод**
2. Выберите **Клавиатуры** или **Методы ввода**
3. Включите **Русская клавиатура**
4. Установите её как клавиатуру по умолчанию (опционально)

## Использование

### Основные функции

- **Переключение языка**: Нажмите кнопку `EN`/`RU` в нижнем ряду клавиатуры
- **Цифры и символы**: Нажмите кнопку `123` для переключения на цифровую раскладку
- **Возврат к буквам**: Нажмите `АБВ` или `ABC` для возврата к буквенной раскладке
- **Shift**: Нажмите `⇧` для ввода заглавной буквы (однократное нажатие)
- **Backspace**: Кнопка `⌫` удаляет символ слева от курсора
- **Enter**: Кнопка `↵` переводит на новую строку

### Предложения слов

- Начните вводить слово на русском языке
- Предложения появятся в верхней панели
- Нажмите на предложение для автоматического завершения слова
- Система запоминает введенные вами слова для улучшения предложений

## Разработка и кастомизация

### Добавление новых слов в словарь

Откройте `entry/src/main/ets/model/SuggestionEngine.ets` и добавьте слова в массив `commonWords`:

```typescript
const commonWords = [
  'привет', 'пока', 'спасибо',
  // Добавьте свои слова здесь
  'новое_слово'
];
```

### Изменение раскладки

Раскладки определены в `entry/src/main/ets/model/KeyboardLayout.ets`. Вы можете:

1. Изменить существующие раскладки
2. Добавить новые символы
3. Создать собственные раскладки

Пример добавления новой клавиши:

```typescript
{ label: 'ё', value: 'ё', shift: 'Ё' }
```

### Изменение стилей

Стили клавиш настраиваются в `entry/src/main/ets/components/KeyButton.ets`:

```typescript
.backgroundColor('#FFFFFF')  // Цвет фона
.fontColor('#000000')        // Цвет текста
.fontSize(18)                // Размер шрифта
.borderRadius(5)             // Радиус скругления
```

## API HarmonyOS

Проект использует следующие API HarmonyOS:

- `@ohos.InputMethodExtensionAbility` - базовый класс для расширения метода ввода
- `@ohos.inputMethodEngine` - движок метода ввода для управления клавиатурой
- `@ohos.window` - управление окном клавиатуры
- `@ohos.display` - получение информации о дисплее

## Известные ограничения

- Словарь предложений пока ограничен (около 100 слов)
- Нет поддержки автокоррекции
- Нет поддержки жестов (swipe typing)
- Нет настроек клавиатуры в UI
